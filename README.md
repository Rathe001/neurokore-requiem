# Neurokore: Requiem

A Diablo 2-style ARPG set in a campy 80s sci-fi / Neuromancer cyberpunk hybrid world.

## About

Neurokore: Requiem blends the neon-soaked chrome aesthetic of 80s science fiction with the neural implants and corporate dystopia of classic cyberpunk. Hack, slash, and jack in.
