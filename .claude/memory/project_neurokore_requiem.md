**Neurokore: Requiem** is a Diablo 2-style isometric pixel art ARPG set in a cyberpunk world. Early design phase, tech stack TBD.

**Why:** This is an ongoing creative/design collaboration.
**How to apply:** Use this as the primary context when the user asks for help with game design, mechanics, lore, writing, or related tasks.

## Genre & Tone
- Diablo 2-style ARPG: hack-and-slash, loot-driven, deep build crafting
- Gritty neon-noir baseline + campy 80s sci-fi surface + 80s body horror edge (The Thing, Videodrome)
- Core tension: technological vs. monstrous

## Design Pillars
- Class identity is paramount — each class plays like a different game mode
- Class-specific resource systems (NOT shared across classes)
- Deep build diversity through itemization
- Loot should create build desire

## Classes (2 at launch)

### CYBORG
*Traded flesh for machine. More augmentation = less human.*
- Base resources: Power Grid + Bandwidth + Memory/CPU
- **Forged (Melee):** Power Grid (budget, not pool). Overclock for burst at risk of brownout.
- **Automaton (Mid-Range):** Bandwidth. Commands drones via loot-based IF/THEN scripts. Drones = physical script expression.
- **Polymath (Ranged):** Memory (loaded abilities) + CPU (cast speed/complexity). Fragmentation = memory degrades mid-combat.

### HUMAN
*Unaugmented. Power comes from what Cyborgs cut away.*
- Base resources: Adrenaline + Composure + Sanity
- **Survivalist:** Adrenaline (builds under pressure). Thrives in chaos, jury-rigged weapons.
- **Gentleman/Lady (gender-matched title):** Composure (maintained through deliberate play). Old-world refinement, dueling/marksmanship.
- **Enculted:** Sanity (depletes with occult use). Tapped into something ancient in the network. Horror-edged.

## Specialization System
- Base form runs all 3 resource meters simultaneously; one skill per resource introduced early
- Choosing a spec = commit to one resource, other two meters vanish from UI
- Unlocked via thematic quests (WoW Legion artifact quest style)

## Spec-Specific Monster Variants
Certain enemies have variants tailored to threaten specific specs via their resource system:
- Cyborg Base: Caustic Beetle | Forged: Nanobytes Swarm | Automaton: Software Bug | Polymath: Hallucination
- Human Base: Wraith | Survivalist: Irradiated Spider | Gentleman/Lady: Heathen | Enculted: Unbeliever

## Visual Style
- Isometric pixel art, modern fidelity (not chunky retro)
- Dark desaturated base + neon pops (teal/cyan dominant, hot pink/red accents)
- Real-time dynamic lighting
- ~25fps animation (D2 tradition)
- Animated pixel portrait busts for NPCs (Bard's Tale 1 style)
- Fixed isometric camera, no rotation/zoom

## Level Design
- Tile-based procedural generation + hand-crafted rooms for events/bosses/story moments
