# Inspirations & References

## Primary Game Inspirations

### Diablo 2
The foundational reference for genre, feel, and structure.

- Deliberate, weighted, build-dependent combat
- Loot-driven progression — gear defines the build, not just the character level
- Distinct monster families with shared visual language per zone
- Skill synergies creating hidden build multipliers
- Act structure giving each area a distinct biome and tone
- Flavor text and environmental storytelling over cutscene-heavy narrative

### Project Diablo 2 (PD2)
The mod that demonstrated how much further the D2 design space could go. Key lessons:

- **Build diversity per class** — PD2's expanded runewords and skill changes revealed how many viable builds were latent in the original system
- **Oskills and off-class abilities on items** — finding a piece of gear that grants another class's skill creates cross-class fantasy and build desire
- **Itemization as the engine of replayability** — when a single item drop can make you want to reroll a character, the loot system is working correctly
- The gap between "functional" and "optimal" should be wide enough that dozens of build paths exist through it

### Vampire Survivors
Reference for end-game enemy density and screen-filling horde scale. The feeling of being overwhelmed by sheer numbers, and the satisfaction of a build that handles it, is the end-game target for Neurokore: Requiem. The scale — not the auto-fire mechanic — is the reference.

### World of Warcraft: Legion
Reference specifically for the spec unlock system. Legion artifact weapon quests were memorable because they were tailored to the class fantasy — the quest felt like the spec choosing you, not a menu option. The Neurokore spec unlock quests should achieve the same effect.
